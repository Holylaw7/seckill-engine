# Codex 日常开发提示词模板

继续开发 Seckill-Engine 项目。

## 当前任务

当前阶段：

`Phase X`

开发模块：

`【填写模块名称】`

## 开发前检查

严格执行：

1. 阅读当前代码结构。
2. 检查 Git 状态。
3. 分析已有设计文档。
4. 检查相关接口、数据库表、Redis Key 和 MQ 契约。
5. 提出实现方案。
6. 等待用户确认。
7. 开始编码。

## 编码要求

- 遵守现有架构。
- 不破坏已有接口。
- 不改变未授权的业务逻辑。
- 添加必要测试。
- 添加必要日志。
- 添加异常处理和参数校验。
- 关注并发安全、幂等性和数据一致性。
- 不引入没有必要的新抽象或依赖。

## 完成后

执行：

```text
git status
mvn test
```

然后提交 Git，并输出：

- commit id
- 修改文件列表
- 测试结果
- 风险说明

## 架构问题处理

如果发现架构问题、接口契约问题、数据一致性问题或明显性能瓶颈：

1. 停止直接修改相关架构。
2. 明确问题、影响范围和复现证据。
3. 提出重构或修复方案。
4. 说明兼容性、迁移和回滚策略。
5. 等待用户确认后再实施。
