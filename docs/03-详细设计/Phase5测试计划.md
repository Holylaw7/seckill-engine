## 1. 单元测试

| 测试项 | 内容 | 通过标准 |
| --- | --- | --- |
| Lua 测试 | 库存充足/不足、重复抢购、未预热、并发扣减（真实 Redis，多线程 1000 并发） | 返回码正确、库存不为负、无重复标记 |
| 订单状态流转 | CREATE→WAIT_PAY→PAY_SUCCESS/CANCEL/TIMEOUT、PAY_SUCCESS→REFUND、非法跳转 | 合法流转成功，非法跳转拒绝，version 冲突不覆盖 |
| 幂等测试 | 重复提交、重复消息、重复支付回调 | 仅一条订单/一次状态变更，返回首次结果 |
| Snowflake 测试 | 唯一性、趋势有序、时间回拨（<5ms 等待、≥5ms 快速失败） | 百万级生成无重复 |
| 事务边界测试 | pre_deduct INIT→SUCCESS/FAIL、消费事务提交后才 ACK | 与《事务边界说明》一致 |

## 2. 集成测试

| 组件 | 覆盖内容 |
| --- | --- |
| Redis | 预热、Lua 扣减/回补、购买标记 TTL、Sentinel 切换、key 同槽校验 |
| RocketMQ | 事务消息提交/回滚/回查、消费重试、DLQ 生成与重放、消息幂等 |

集成测试使用 Testcontainers 或独立测试环境（真实 Redis/RocketMQ/MySQL）。

## 3. 并发与压力测试

目标基线（冻结）：**10,000 QPS、10,000 并发、库存 1,000**。

验证项：

1. 零超卖：库存不为负、成交数量 ≤ 1,000；
2. 零重复订单：同一用户同场次同商品仅一条有效订单；
3. 最终一致：预扣/订单/库存收敛 ≤ 5 秒；
4. P99 RT ≤ 200ms（秒杀接口）；
5. 非法/超量请求拦截 ≥ 90%。

工具与口径：JMeter 分布式压测；测试环境（Redis Sentinel + RocketMQ + MySQL）与生产同构；每次压测输出 QPS、RT 分布、错误率、库存与订单核对结果。

## 4. 故障测试

| 场景 | 预期 |
| --- | --- |
| Redis 宕机 | 快速失败（BUSY），不超卖，恢复后数据校准 |
| MQ 积压/不可用 | 发送失败回补，消费积压告警，恢复后补偿收敛 |
| MySQL 故障 | 订单落库失败回补，不产生悬挂库存 |
| 单实例下线 | 无状态服务自动摘除，请求不失败（多实例） |
