# Seckill-Engine 异常分类表（Phase 3 冻结）

| 项目 | 内容 |
| --- | --- |
| 文档版本 | v1.0（冻结） |
| 状态 | 已评审冻结 |
| 日期 | 2026-08-01 |

| 异常 | 检测方式 | 处理方式 | 补偿方式 |
| --- | --- | --- | --- |
| Redis 异常 | 客户端异常/超时、Sentinel 探活、Lua 返回码、指标（错误率/连接数） | 熔断快速失败（**禁止 DB 直扣**）、只读降级（本地缓存/DB）、告警 | 恢复后以 MySQL 校准 Redis（repair 锁 + REPAIR 流水）；库存 key 丢失走预热/修复重建 |
| MQ 异常 | 发送异常/超时、消费异常、积压指标（>10 万）、DLQ 告警、回查次数 | 发送失败→Lua 回补+快速失败；消费失败→延迟重试 16 次→DLQ；积压→扩容/限流 | 对账任务重投 CREATE_ORDER（≤3 次）或触发 STOCK_RECOVER；DLQ 人工重放 |
| MySQL 异常 | 连接池耗尽、慢 SQL、锁等待、DuplicateKey、事务失败 | 幂等重试（可重试类）、快速失败、降级查询缓存、告警 | 订单落库失败→回补库存；数据差异→修复任务+人工审批 |
| 网络超时 | 网关/Feign/渠道调用超时监控（3s） | 快速失败，不盲目重试，客户端轮询结果接口 | 幂等重试（写接口按业务键）；查询类由结果接口兜底 |
| 重复消息 | messageId 幂等表冲突、订单唯一约束冲突 | 幂等返回首次结果，丢弃重复消息（CONSUME_SUCCESS） | 无（天然幂等） |
| 支付回调重复 | 回调流水号唯一、幂等表冲突 | 验签后幂等处理，返回首次结果 | 无；订单/支付状态异常由查单任务定时补偿 |

通用规则：

- 所有补偿动作必须幂等（唯一流水 + 唯一约束）；
- 所有异常必须告警与留痕（traceId 贯穿）；
- 可重试与不可重试分类：可重试（DB 抖动、锁冲突、依赖超时）；不可重试（参数/消息结构非法、业务数据非法）。
