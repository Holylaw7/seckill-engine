## 1. 设计目标

1. 统一协议、统一返回结构、统一错误码，前后端契约先行；
2. 核心写接口幂等，重复提交/重放无副作用；
3. 安全基线：JWT 鉴权、回调验签、防刷、黑名单、防越权；
4. 可演进：`/api/v1` 前缀，未来 `/api/v2` 兼容。

## 2. 通用规范

| 项 | 约定 |
| --- | --- |
| Base URL | `/api/v1` |
| Content-Type | `application/json;charset=UTF-8` |
| 认证 | `Authorization: Bearer {token}`（login/callback 除外） |
| 幂等 | 写接口按业务键幂等：秒杀=user+session+sku；订单=orderId；支付=paymentNo |
| 金额 | 统一使用字符串传输（如 `"99.00"`），避免精度丢失 |
| 时间 | 毫秒时间戳（Long） |
| 分页 | 请求 `page`/`pageSize`，响应 `{page,pageSize,total,items}` |
| 链路 | 网关生成 `traceId`，全链路透传，响应返回 |

## 3. 统一返回结构

```json
{
  "code": 0,
  "message": "success",
  "traceId": "trace-0001",
  "data": {},
  "timestamp": 1782892800000
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| code | Integer | 0 成功，非 0 见错误码表 |
| message | String | 提示信息（对用户可展示） |
| traceId | String | 全链路追踪 ID |
| data | Object | 业务数据（分页结构见上） |
| timestamp | Long | 服务端时间戳 |

HTTP 状态约定：业务结果一律 200 + code；401 未登录、403 无权限/黑名单、404 不存在、409 状态冲突、429 限流、503 系统繁忙。

## 4. 错误码设计

分段（冻结）：`10xxx` 系统通用，`20xxx` 认证，`30xxx` 秒杀业务，`40xxx` 订单业务，`50xxx` 支付业务。

## 5. Gateway API 与路由

| 路由前缀 | 目标服务 | 鉴权 |
| --- | --- | --- |
| `/api/v1/auth/**` | auth-service | login 放行，其余需 token |
| `/api/v1/seckill/**` | seckill-service | 需 token |
| `/api/v1/orders/**` | order-service | 需 token |
| `/api/v1/payments/**` | payment-service | 需 token（callback 放行验签） |
| `/api/v1/admin/**` | 各服务管理端 | 需 token + 管理员角色 |

网关行为：JWT 校验、限流（IP/用户/API）、黑名单拦截、traceId 生成透传、防重放（timestamp + nonce，预留）。

## 6. 秒杀接口（seckill-service）

### 6.1 发起秒杀

`POST /api/v1/seckill/execute`

请求：

```json
{
  "sessionId": 30001,
  "skuId": 20001,
  "quantity": 1
}
```

响应：

```json
{
  "code": 0,
  "message": "success",
  "traceId": "trace-0001",
  "data": {
    "result": "SUCCESS",
    "orderId": "SO1754000000000000001",
    "payDeadline": 1782894000000
  },
  "timestamp": 1782892800000
}
```

`result` 取值：`SUCCESS`（预扣成功，订单异步创建）/ `STOCK_EMPTY` / `REPEAT_BUY` / `NOT_READY` / `BUSY`。

说明：接口同步返回预扣结果，订单由 MQ 异步落库；幂等键 = user + session + sku；限流维度：用户 5 QPS 突发 10、接口总量按压测配置。

### 6.2 查询秒杀结果

`GET /api/v1/seckill/result?sessionId=30001&skuId=20001`

响应 data：`{ "status": "NONE|DEDUCTED|SUCCESS|FAILED", "orderId": "...", "payDeadline": 0 }`（状态机冻结见 seckill-service 设计 B.3；轮询间隔由客户端控制，服务端建议 500ms）。

### 6.3 场次信息

`GET /api/v1/seckill/session/{sessionId}` → 场次详情（开始/结束/状态/限购数，读缓存）；  
`GET /api/v1/seckill/sessions?activityId=1&page=1&pageSize=10` → 场次列表。

## 7. 订单接口（order-service）

| 接口 | 说明 | 关键响应 |
| --- | --- | --- |
| `GET /api/v1/orders/{orderId}` | 订单详情（含明细） | orderNo、status、amount、payDeadline、items |
| `GET /api/v1/orders?status=WAIT_PAY&page=1&pageSize=10` | 我的订单列表（强制按 token 的 userId 查询） | 分页结构 |
| `POST /api/v1/orders/{orderId}/cancel` | 取消订单（WAIT_PAY→CANCEL） | 取消结果 + 回补说明 |
| `GET /api/v1/orders/{orderId}/status` | 查询订单状态 | orderStatus、payDeadline |

越权控制：订单查询/操作必须 `user_id == token.userId`，否则 10003。

## 8. 支付接口（payment-service）

| 接口 | 说明 |
| --- | --- |
| `POST /api/v1/payments/create` | 入参 `{orderId}`，出参 `{paymentNo, channelParams}`（渠道参数） |
| `POST /api/v1/payments/callback/{channel}` | 渠道回调：独立验签、幂等（回调流水号）、无 Bearer 鉴权 |
| `GET /api/v1/payments/{paymentNo}` | 查询支付状态 |
| `POST /api/v1/payments/{paymentNo}/refund` | 退款（管理端/受控接口），幂等按退款申请号 |

回调处理：验签失败返回 22002；重复回调返回首次结果（22003 语义为幂等成功）。

## 9. 管理接口（admin）

| 接口 | 说明 |
| --- | --- |
| `POST /api/v1/admin/activities` | 创建活动 |
| `POST /api/v1/admin/sessions` | 创建场次（含开始/结束时间、限购） |
| `POST /api/v1/admin/sessions/{sessionId}/publish` | 发布场次（触发预热） |
| `POST /api/v1/admin/skus` | 配置秒杀商品（库存投放、价格） |
| `POST /api/v1/admin/blacklist` | 拉黑/解封（用户/IP/设备） |
| `GET /api/v1/admin/stocks?sessionId=1` | 库存对账视图（Redis vs MySQL） |
| `GET /api/v1/admin/metrics` | 监控指标聚合（Phase 7 完善） |

管理接口全部要求管理员角色 + 操作审计日志。

## 10. 安全设计

- JWT：登录签发 access token（2h），Redis 会话支撑校验与吊销；
- 回调验签：渠道 RSA/HMAC 验签 + timestamp/nonce 防重放，幂等落库；
- 防刷：频次限流（risk:rate:*）+ 黑名单 + 设备指纹（预留）+ 验证码扩展接口（预留）；
- 脱敏：手机号等敏感字段响应脱敏；
- 防越权：所有用户数据查询绑定 token userId。

## 11. 异常场景

| 场景 | 行为 |
| --- | --- |
| 限流命中 | 429 + 12001，提示稍后重试 |
| Redis/MQ 故障 | 503 + 20006 快速失败，不排队 |
| 重复提交 | 幂等返回首次结果，不产生新订单 |
| 回调与关单并发 | 状态机 + version 乐观锁，冲突返回 21002/409 |
| 网关超时 | 3s 超时快速失败，客户端轮询结果接口 |
