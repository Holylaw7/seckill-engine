# 文档目录

所有阶段文档统一存放在 `docs` 下，按阶段分子目录维护：

```text
docs
├── 01-需求分析       # Phase 1
├── 02-架构设计       # Phase 2
├── 03-详细设计       # Phase 3
├── 04-测试报告       # Phase 5
├── 05-性能优化       # Phase 6
└── 06-部署运维       # Phase 7
```

## 命名与维护约定

- 文档按阶段创建，评审通过后随代码一同提交，保证可追溯。
- 需求、接口、设计变更必须同步更新对应文档，禁止只改代码不改文档。
- 涉及外部评审的文档在评审通过后打版本 tag。
